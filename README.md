# Problem 3: Tip Calculator Using JavaFX

## Aim
To develop a Tip Calculator using JavaFX components and event handling.

## Components Used
- Label
- TextField
- Button
- GridPane
- HBox
- VBox

## Description
This application calculates the tip amount and total bill based on the bill amount and tip percentage entered by the user.

The Calculate button performs the calculation. The Clear button resets the input fields and results.

## Formula
Tip Amount = Bill Amount × Tip Percentage / 100

Total Bill = Bill Amount + Tip Amount

## Example
Bill Amount = ₹500

Tip Percentage = 10%

Tip Amount = ₹50.00

Total Bill = ₹550.00

## Procedure
1. Create a JavaFX project.
2. Create the TipCalculatorApp.java file.
3. Add labels, text fields and buttons.
4. Write the calculation logic using event handling.
5. Run the application and test the output.

## Result
Successfully developed a JavaFX Tip Calculator that calculates the tip amount and total bill.

## Requirements
- JDK 17 or later
- JavaFX libraries
- Maven (if using the supplied Maven project)
